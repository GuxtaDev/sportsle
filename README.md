**Sportsle.games**

Jogo de adivinhação sobre atletas, inspirado nos jogos estilo "dle" (como o Wordle). O jogador tenta descobrir quem é o atleta misterioso a partir de dicas reveladas de forma progressiva.

Projeto integrador desenvolvido em equipe na turma de Informática do IFSC – Câmpus Garopaba, premiado com o 3º lugar na SNCT 2024 (Semana Nacional de Ciência e Tecnologia).

**Sobre o projeto**

O Sportsle combina diversão e aprendizado. A ideia é promover o reconhecimento de atletas por meio de um jogo, incentivando o interesse por esportes e valorizando atletas de diferentes modalidades e gêneros.

Status: o domínio do site expirou e a versão online não está mais no ar. O projeto pode ser executado localmente seguindo as instruções abaixo.





# **Requisitos:**

## Para rodar 'create_db.py'

```
pip install openpyxl

pip install pandas
```

## **Para rodar 'app.py'**

```
pip install flask
```

```
pip install flask_cors
```

```
pip install requests
```
